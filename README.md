# Anzenna Homebrew Tap

Homebrew formulae for Anzenna tools.

Installation and usage instructions live at
[docs.anzenna.ai](https://docs.anzenna.ai) — for AI DLP, see
[Install AI DLP via Homebrew](https://docs.anzenna.ai/docs/ai-dlp/homebrew).

For help, contact [Anzenna support](mailto:support@anzenna.ai). To report a
security issue, email [security@anzenna.ai](mailto:security@anzenna.ai) rather
than opening a public issue.
